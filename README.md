# Mini Projects in React

This repository contains a collection of **12 mini projects** developed with **React**. These projects range from basic applications to more complex ones, providing an opportunity to explore React's capabilities and improve web development skills.

## Projects

1. **Password Generator**: A random password generator tool.
2. **Theme Toggler**: Toggle between light and dark themes.
3. **Create Your Own Country**: Build your custom country with React components.
4. **To-Do List**: A simple to-do list project to manage tasks.
5. **To-Do Redux**: A to-do list app that uses Redux for state management.
6. **Currency Converter**: Convert currencies based on live exchange rates.
7. **Real Complete Website**: A complete small-scale website showcasing various features built with React.
8. **Weather App**: Displays weather information for various locations.
9. **Recipe Finder**: Search for recipes using an external API.
10. **Movie Finder**: Search movies using a third-party API.
11. **Blog App**: A blog platform where you can read, create, edit, and delete posts.
12. **Calculator**: A simple calculator app built with React.

## Tech Stack

- **Frontend**: React
- **State Management**: Redux (for some projects)
- **APIs**: External API integration for projects like Currency Converter, Recipe Finder, and Movie Finder.
